# Personal website

The site is mostly a **Vue 3** app in **TypeScript**, bundled with **Vite**; a few **React** components are used for specific UI effects. Routes are generated from the file tree via **unplugin-vue-router**; **Pinia** handles state. Styling uses **Element Plus**, **Tailwind CSS**, and **Motion** for animation. The production build is a static SPA, deployed on **Vercel**.
