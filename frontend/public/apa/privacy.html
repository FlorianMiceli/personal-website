Privacy policy

APA Agenda · last updated 7 November 2026

Who uses it

APA Agenda is a private tool used only by its author, Florian Miceli, with his own Google account.

What data it accesses

With the permissions granted on the Google consent screen, it reads calendars, calendar events, task lists and tasks, and creates new calendar events and tasks. It does not modify or delete existing events or tasks.

Where the data goes

Data retrieved from Google is processed on the author's own computer only. It is not sold, shared with third parties, sent to external AI services or used for advertising. The OAuth token is stored locally on that computer.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google account permissions.
